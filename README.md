 # ✅ TickTick-Inspired Task Manager (Frontend)

This is the frontend for a recurring task management app built using **Next.js**, inspired by **TickTick**. Users can create, view, and manage tasks with recurring schedules and visual recurrence previews.

---

## 🛠️ Tech Stack

- **Next.js 14** (App Router)
- **React**
- **Tailwind CSS** (UI styling)
- **Zustand** (state management)
- **Date-fns** (date handling)
- **Axios** (API requests)
- **PostgreSQL Backend** (integrated via REST)

---

## 📸 Features

- 🔁 **Create recurring tasks**
- 📅 **Recurrence Picker** and visual **calendar preview**
- 📝 Add/update/delete tasks
- 💾 Local state management with Zustand
- 🎨 Clean, responsive UI with Tailwind

---

## 🚀 Getting Started

### 1. Clone the repository

git clone https://github.com/Ranjanigit123/TickTick-fe.git
cd TickTick-fe

### 2. Install dependencies
npm install

### 3. Configure .env.local
Create a .env.local file at the root and add:
NEXT_PUBLIC_API_URL=http://localhost:5000

### 🔧 Run the Development Server

npm run dev
###  Open http://localhost:3000 in your browser.
